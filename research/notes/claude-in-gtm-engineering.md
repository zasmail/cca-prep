## Core Claims

1. Non-technical roles can design production AI solutions when the friction to Claude is eliminated through simple abstractions (prompts + context + patterns).
2. The AE workflow bottleneck is not email volume but fragmented context discovery across Slack, Docs, and internal systems.
3. System prompts encoding role identity + customer context enable domain-specific reasoning without re-explaining on every query.
4. Context retrieval from multiple sources (Google Docs, web URLs, internal docs) is mandatory for generating locally coherent drafts.
5. Operational burden reduction (2-3 hours/day on email) creates cognitive slack for strategic high-leverage work.
6. Career velocity and scope increase when technical gatekeeping dissolves—non-engineers can now architect solutions, not just request them.

## Patterns & Frameworks

- **System Prompt Architecture**: Name + Role + Customer Context → Claude → Behavioral coherence
- **Context Retrieval Pipeline**: Multi-source fetch (Google Docs, URLs, Slack) → Centralized injection → Reduced cognitive load for user
- **Draft Generation Workflow**: Email trigger → Context load → System prompt inject → Generation → User review
- **Pattern Matching on Inbound**: Classify email type/customer → Route to relevant knowledge base → Generate contextualized response

## Applied AI Relevance for Anthropic Applied AI Engineers

- **Abstraction design matters**: Non-technical end users adopt AI workflows when the entry point is 3 inputs (name, role, context doc) not 10 config knobs. Map user workflows first, then simplify the interface.
- **Context management is the leverage point**: For knowledge workers, solution quality depends entirely on retrieval—hook into their existing systems (Slack, Docs, email) before inventing new ones.
- **System prompts can encode organizational identity**: Use role + customer type to create consistent tone/reasoning across generated outputs; this scales human judgment without per-query intervention.
- **Measure operational impact + career impact**: Track time saved AND role expansion; the business case for AI-enabled GTM scales when it enables people to do fundamentally new work, not just faster work.
