| 13 | Anthropic's own **Advanced Tool Use** engineering post (Nov 24, 2025) shipped **Tool Search Tool** (keeps tool definitions out of context until requested — supports scaling to thousands of tools) and **Programmatic Tool Calling** (Claude writes code in a sandbox to call multiple tools and pre-process results before anything hits context, collapsing N tool round-trips into one). Both beta at launch (`advanced-tool-use-2025-11-20` header); code execution, memory, programmatic tool calling, tool search, and tool-use examples are now listed as generally available on the current tool-use docs. | https://www.anthropic.com/engineering/advanced-tool-use ; GA status via https://platform.claude.com/docs/en/agents-and-tools/tool-use/overview | "Claude only sees the tools it actually needs for the current task." / "Claude writes code that calls multiple tools, processes their outputs, and controls what information actually enters its context window." | Confirmed |

**Audit relevance:** CLAUDE.md's anti-pattern #8 ("More than 5 tools per agent / 18+ tools degrades selection reliability") is a *pre*-Tool-Search-Tool heuristic. As of Nov 2025, Anthropic's own guidance is that tool-count ceilings are now an architectural choice to solve with Tool Search / Programmatic Tool Calling, not a hard cap — this is the single highest-value update for D2 (Tool Design) if the exam blueprint hasn't caught up.
