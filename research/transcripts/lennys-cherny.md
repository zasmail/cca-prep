## Episode overview

Boris Cherny, creator and head of Claude Code at Anthropic, discusses the product's
trajectory from a personal terminal prototype to a tool reportedly behind roughly 4% of
public GitHub commits, with daily active users said to have doubled in the month before
the episode aired.

## Topics covered (per show notes)

1. **Growth trajectory** — how Claude Code went from an internal prototype to a
   large-scale coding tool used across the industry.
2. **Product principles** — counterintuitive strategic choices Boris credits for Claude
   Code's traction (e.g., resisting feature bloat, keeping the tool simple/composable).
3. **"Coding is solved"** — Boris's framing of what it means for coding-as-a-bottleneck to
   be largely resolved by current models, and what that implies for the next wave of
   agentic products.
4. **Latent demand** — how unmet demand for agentic tooling shaped both Claude Code and
   the newer "Cowork" product line.
5. **Practical usage tips** — guidance for getting more out of Claude Code day to day.
6. **Team structure philosophy** — Boris's view that deliberately under-resourcing a team
   on headcount while giving it effectively unlimited compute/token budget produces better
   AI products than the inverse (well-staffed, budget-constrained teams).
7. **Career detour** — Boris briefly left Anthropic for Cursor before returning within
   about two weeks; the episode touches on what prompted the return.
8. **Leadership principles** — three core principles Boris says he repeats to every new
   hire on the Claude Code team (specific content not detailed in the show notes text
   available on the page).
